# Air Quality Index (AQI) Prediction 🌫️

Used machine learning to predict AQI levels and interpret feature impacts using explainable AI.

## 📈 Objective
- Train a regression model to predict AQI
- Use LIME for model explainability
- Highlight key factors affecting air quality in different months of the year

## 🧰 Tools & Techniques
- Python (XGBoost, Pandas, Scikit-learn)
- LIME for explainability
- Matplotlib, Seaborn for visualization

## 🔍 Results
- Achieved high accuracy with XGBoost
- LIME explained predictions in local instances
